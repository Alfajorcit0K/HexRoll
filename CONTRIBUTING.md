# Contribuir

Puedes proponer correcciones, mejoras de accesibilidad y contenido mediante issues o pull requests. Las contribuciones al código original se ofrecen bajo MIT.

## Preparar un cambio

1. Usa Node.js 20 o posterior. No hay dependencias que instalar.
2. Ejecuta `npm test`.
3. Prueba el editor con `npm start`.
4. Para cambios visuales, prueba ambas variantes y el widget como fuente local en OBS.

## Catálogo

Conserva los identificadores existentes: las selecciones de cada usuario dependen de ellos. Evita duplicados y comprueba las rutas de las imágenes. Las plantillas de referencia son `widget-template.html` y `widget-template-lite.html`; los HTML de las ruletas se generan automáticamente.

No incluyas claves ni datos personales. No añadas imágenes u otros recursos de terceros sin derechos suficientes para su redistribución. Consulta `THIRD_PARTY_NOTICES.md` antes de proponer cambios a esos recursos.
